Privacy policy

n8n personal · last updated 12 November 2026

Who uses this app

n8n personal is used only by its owner, to automate their own tasks. It is not offered to the public.

What data it accesses

With the owner's permission, the app reads and changes files in the owner's Google Drive and Google Sheets (for example: reading photos, sharing a file by link, adding spreadsheet rows, moving files between folders). It accesses nothing else.

How data is processed and stored

  • Processing runs on the owner's own computer. Google sign-in tokens are stored there, encrypted.
  • Data is not sold, shared with third parties, used for advertising, or used to train AI models.
  • Images are analysed by an AI model running locally on the owner's computer, not by a cloud service.

Google API data

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions.
